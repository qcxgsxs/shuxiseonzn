# assets/README.md

请把你提供的图片放到此目录，文件名要求如下（与前端与扩展约定）：

- icon.png      -> 插件图标（用于扩展与仪表盘 logo），建议 512x512 PNG
- bg1.png       -> 仪表盘背景图（将作为轮播第1张）
- bg2.png       -> 仪表盘背景图（第2张）
- bg3.png       -> 仪表盘背景图（第3张）

你在聊天中上传的图片（图一、图二、图三、图四）请按以下规则命名并上传到本目录：
- 使用图一作为 icon.png
- 使用图二、图三、图四 中的任意三张分别命名为 bg1.png, bg2.png, bg3.png（可以重复使用图片，但必须确保这三项存在）

如何替换（本地）：
1. 在仓库根目录下创建 assets/ 目录（如果不存在）。
2. 把图片文件复制到 assets/ 并命名为 icon.png, bg1.png, bg2.png, bg3.png
3. 刷新前端页面（frontend/index.html）即可看到背景轮播与图标更新。

可选：如果你希望我直接把聊天中上传的图片添加到仓库，请明确回复“请上传我已提供的图片到仓库”，我将在收到确认后把图像文件提交到 assets/ 目录并生成所需 icon 尺寸（16/48/128/512）。
